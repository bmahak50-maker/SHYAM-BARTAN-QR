## Publish to your existing GitHub Pages repository
1. Extract this ZIP.
2. Open your repository and choose Add file → Upload files.
3. Upload/replace every file inside `qr_pay_pwa` in the repository root, including `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, and `icon-512.png`. Do not upload only the ZIP.
4. Commit the changes.
5. Wait a few minutes, then open the site in Chrome and refresh it. If the installed app still shows the old icon, remove the old home-screen app and install it again from Chrome.

Important: This QR generator does not verify payment. Confirm payments in the official merchant app/bank account. UPI apps may behave differently about editing the amount. GitHub Pages terms are not intended for sites primarily facilitating commercial transactions; use hosting whose terms permit your intended business use before relying on it long term.
